## ?? Demo Script for Judges

### 1. Show Normal Operation (30 seconds)
- Dashboard shows 3 healthy nodes
- Real-time metrics updating
- ML model active (90%+ accuracy displayed)

### 2. Demonstrate AI Prevention (60 seconds)
- Switch to AI Mode
- Click "Attack" on Node 1
- **Watch:** AI detects latency spike BEFORE breach
- **Watch:** Prediction countdown shows time to breach
- **Watch:** AI reroutes traffic automatically
- **Watch:** Node recovers with animation (RED?ORANGE?GREEN)
- **Result:** Zero downtime, autonomous healing

### 3. Show Enterprise Features (30 seconds)
- Click recovered node ? Decision Receipt modal
- Show audit trail with timestamps (T1, T2, T3)
- Show ML confidence scores
- Show recovery animation proving autonomous healing

### 4. Compare Manual Mode (30 seconds)
- Switch to Manual Mode
- Same attack ? Manual intervention panel appears
- Show reaction time measurement
- Demonstrate human-in-the-loop approach

**Total Demo Time:** 2.5 minutes
**Impact:** Clear, compelling demonstration of AI autonomy
