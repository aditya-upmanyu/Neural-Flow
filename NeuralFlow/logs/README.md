# 📁 Logs Directory

This directory contains runtime logs and persistent data generated by NeuralFlow V4.

## Files Generated at Runtime

These files are created automatically by the backend when events occur:

| File | Purpose | Max Size |
|------|---------|----------|
| `incident_receipts.json` | Decision receipts with audit trail | 200 receipts |
| `benchmark_runs.json` | Resilience benchmark test runs | 500 runs |
| `operator_feedback.json` | Operator feedback on AI decisions | Unlimited |
| `events.json` | Rolling event log | 1000 events |
| `ml_evaluation.json` | Latest ML held-out test results | 1 file |
| `reroute_events.json` | Reroute event history | Unlimited |

## Important Notes

1. **Not Committed to Git**: All `.json` and `.log` files in this directory are gitignored
2. **Created Automatically**: Files are created when the backend starts or when first event occurs
3. **Safe to Delete**: You can delete these files to reset state (backup first!)
4. **Persistent Storage**: Data survives server restarts

## Maintenance

### Backup Logs
```bash
# Create backup
cp logs/incident_receipts.json logs/incident_receipts.backup.json

# Or backup all
tar -czf logs-backup-$(date +%Y%m%d).tar.gz logs/*.json
```

### Clear Logs
```bash
# Remove all runtime data (⚠️ Cannot be undone)
rm logs/*.json

# Backend will recreate files on next run
```

### Export for Analysis
```bash
# Export as CSV (if needed)
node scripts/export-logs.js

# Or use API endpoints:
# GET /api/receipts/export
# GET /api/benchmark/export
```

## Disk Space Management

Files automatically limit their size:
- `incident_receipts.json`: Max 200 entries (oldest removed)
- `benchmark_runs.json`: Max 500 entries (oldest removed)
- `events.json`: Max 1000 events (rolling window)

Estimated max disk usage: **~10-50 MB** depending on activity.
